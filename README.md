# Smart_Qplay

A HTML5-based MP3 player with Winamp-inspired visualizations.

## Run the player

Once GitHub Pages is enabled and the site deployment has completed, open:

**https://quadrant2005.github.io/Smart_Qplay/**

The player runs in the browser. Add local audio files or playlists using **Load MP3s / PL** or drag and drop. Files are loaded locally in your browser and are not uploaded to this repository.

## GitHub Pages setup

The repository includes a GitHub Actions workflow that publishes the site whenever changes are pushed to `main` (and can also be run manually). In the repository settings, go to **Settings → Pages** and set the build and deployment source to **GitHub Actions**. Wait for the workflow to finish, then use the URL above.

This repository is currently private. A public-facing page that anyone can open requires making the repository public, or using a GitHub plan/organization setup that supports public Pages access from a private repository. Otherwise, access to the site remains restricted according to your GitHub Pages and repository visibility settings.
